# E-Commerce Customer Analysis (ShopSmart)

Predictive modeling and behavioral analysis of online retail customers to drive conversion, retention, and personalized marketing.

---

## 📂 Project Files

| File | Description |
| :--- | :--- |
| `shop_smart.ipynb` | End-to-end data analysis notebook analyzing customer purchase patterns, session times, and classification targets |
| `shop_smart_ecommerce.csv` | Transactional customer dataset with behavioral, demographic, and spending variables |

---

## 🎯 Objective & Workflow

1. **Exploratory Data Analysis (EDA)**:
   - Investigating customer lifetime value, browsing sessions, cart abandonment rates, and seasonal trends.
2. **Feature Engineering**:
   - Creating derived ratios such as average order value (AOV), session-to-purchase ratios, and frequency indicators.
3. **Classification Modeling**:
   - Training classification models to identify churn-prone customers or predict purchase conversion.
4. **Actionable Business Insights**:
   - Identifying the highest-impact factors driving customer conversion and retention.
