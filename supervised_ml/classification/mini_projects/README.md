## 🧭 Standard Mini-Project Structure

Each mini-project folder is self-contained with:
1. **Local Dataset**: CSV or JSON data files stored directly with the notebook for standalone execution.
2. **Jupyter Notebook**: Complete pipeline containing exploratory data analysis (EDA), data cleaning, feature encoding, model training, hyperparameter optimization, and evaluation metrics.
3. **Dedicated Documentation**: Project-specific README explaining variables, insights, and findings.
