## 🎯 Visualization Fundamentals

Effective data visualization communicates patterns, distributions, correlations, and anomalies:

- **Distributions**: Histograms (`plt.hist()`), KDE density plots, Box plots (`sns.boxplot()`).
- **Relationships & Correlation**: Scatter plots (`plt.scatter()`), Pair plots (`sns.pairplot()`), Heatmaps (`sns.heatmap()`).
- **Comparisons**: Bar charts (`plt.bar()`), Categorical plots.
- **Trends**: Line charts (`plt.plot()`), Time-series plots.
